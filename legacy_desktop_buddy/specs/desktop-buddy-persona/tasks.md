# 自定义性格与性格化互动任务计划（desktop-buddy-persona）

执行顺序：先把数据模型和内置语录包铺好（不依赖模型就能看到效果），再接对话侧人格注入，最后做 AI 语录生成和界面。

- [x] Task 1: 人格数据模型与存储
    - 1.1: `types.ts` 新增 `LineStyle`、`Persona`；`AvatarMeta.persona`、`BuddyConfig.defaultPersona`
    - 1.2: `store.ts` 定义默认人格，旧形象读取时补 `persona: null`
    - 1.3: `manager.ts` 新增 `getPersona(id)` / `setPersona(id, patch)`，删除形象时人格一起删
    - 1.4: 名字上限 10 字、性格描述上限 500 字，保存时截断

- [x] Task 2: 内置语录包扩充与按风格分组
    - 2.1: `resources/lines.json` 改成按 5 种风格分组的结构
    - 2.2: 每种风格写 click 30 条、idle 12 条，保持短句、口语、不重复
    - 2.3: 保留 welcome / error / thinking 三个通用池
    - 2.4: 语录解析逻辑：优先用人格自带语录，否则用风格包，最后兜底 default

- [x] Task 3: 对话侧人格注入
    - 3.1: `client.ts` 改成三段式 system prompt（身份 + 用户性格 + 最高优先级硬约束）
    - 3.2: 硬约束明确四条：60 字上限、无 markdown、必须调用工具、不得因性格拒绝执行
    - 3.3: 每次对话按当前生效形象取人格，形象未设置则用默认人格
    - 3.4: 切换形象后清空对话历史，避免上一个人格的语气串味

- [x] Task 4: AI 语录生成
    - 4.1: `src/main/llm/lines.ts` 实现 `generateLines(persona)`，要求返回严格 JSON
    - 4.2: 宽容解析：整体 parse → 正则抠 JSON → 按行拆分兜底
    - 4.3: 清洗：去引号/markdown、超 20 字截断、去空、去重
    - 4.4: 数量不足时用对应风格的内置包补齐，保证不返回空池
    - 4.5: 未配置模型时不发请求，直接返回明确原因

- [x] Task 5: 设置页性格区块
    - 5.1: 预览区下方新增「性格」区块，作用于当前选中形象
    - 5.2: 名字输入、性格描述多行框（带占位示例与字数计数）
    - 5.3: 语录风格下拉（5 选 1，说明其作为兜底的作用）
    - 5.4: 「按性格生成语录」按钮：禁用/生成中/成功/失败四态
    - 5.5: click / idle 两个语录编辑框，一行一句，可手改后保存
    - 5.6: 「保存性格」按钮，保存后广播刷新

- [x] Task 6: 运行时语录切换
    - 6.1: `App.tsx` 的语录来源改为按当前形象人格解析
    - 6.2: 形象切换事件触发语录池重载
    - 6.3: 切换后气泡显示新人格的欢迎语
    - 6.4: 确认点击响应仍为即时（不引入任何网络调用）

- [x] Task 7: 验证与文档
    - 7.1: 两个形象设置不同性格，验证单击台词与闲聊语气都不同
    - 7.2: 验证冲突性格（要求长回复、拒绝执行）下 60 字限制与工具调用仍生效
    - 7.3: 验证生成返回非 JSON、返回不足、未配模型三种情况的兜底
    - 7.4: `tsc --noEmit` + 构建 + 重新打包 dmg 并覆盖安装
    - 7.5: README 补性格与语录的说明
