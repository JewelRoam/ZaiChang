# AI 生成真 Q 版任务计划（desktop-buddy-ai-chibi）

执行顺序：先把抠图这条已实现的链路在你机器上真正跑通（Q 版依赖它），再改代码接 DashScope，最后联调。

- [x] Task 1: 本地抠图服务就绪（前置依赖）
    - 1.1: 在独立 venv 里安装 rembg，避免污染系统 Python
    - 1.2: 以 HTTP 服务模式启动，监听 127.0.0.1:7000
    - 1.3: 用一张测试图直接打接口，确认返回的 PNG 真的带透明通道
    - 1.4: 给出一条可复用的启动命令，并说明首次调用会下载模型（约 176MB）

- [x] Task 2: 图像接口配置项扩展
    - 2.1: `ModelConfig` 新增 `imageStyle: 'openai' | 'dashscope'` 与 `imageEndpoint`
    - 2.2: `store.ts` 补默认值（默认 dashscope + 官方默认地址），旧配置读取时补字段
    - 2.3: 设置页加协议下拉、完整地址输入框，模型名输入框补 placeholder 提示可用型号
    - 2.4: 协议为 dashscope 时校验地址非空，为空则禁用「AI Q 版」按钮并说明原因

- [x] Task 3: DashScope 协议适配
    - 3.1: `generateChibiDashScope()`：base64 传图、JSON 请求体、90s 超时
    - 3.2: 中文 Q 版 prompt（头身比、保留发型服装配饰、纯色背景、无水印）
    - 3.3: `findImageUrl()` 递归解析响应，不死绑字段路径
    - 3.4: 拿到 OSS 临时 URL 后立即下载转存（URL 24 小时失效）
    - 3.5: 按协议分发：`imageStyle` 决定走 OpenAI 兼容还是 DashScope

- [x] Task 4: 生成后自动抠图
    - 4.1: Q 版生成成功后，若配了抠图接口则自动对结果抠一次
    - 4.2: 抠图失败时保留带底色的 Q 版，提示失败原因，不丢弃已计费的结果
    - 4.3: 未配抠图接口时，结果带底色并在预览区明确提示
    - 4.4: AI Q 版的源图改回用原图（不再用抠图结果，因为顺序反了）

- [x] Task 5: 错误分类与提示
    - 5.1: 404 → 提示地址不完整，指引去文档页复制
    - 5.2: 401/403 → 提示检查地域（北京/新加坡 key 与地址不可混用）
    - 5.3: 429 → 提示图像编辑限流 2 RPM，稍后再试
    - 5.4: 额度不足/欠费 → 透传阿里云原文，不改写成模糊文案
    - 5.5: 响应无图片 → 报错并把响应前 200 字写进日志

- [x] Task 6: 联调与文档
    - 6.1: 用你的百炼 key 实测一次完整链路：生成 → 自动抠图 → 应用到桌面
    - 6.2: 验证产物落在 `avatars/{id}/chibi-ai.png`，重启后仍可用
    - 6.3: 验证五种失败提示可读
    - 6.4: `tsc --noEmit` + 构建 + 重新打包 dmg 并覆盖安装
    - 6.5: README 补百炼配置、rembg 启动方式、「Q 版依赖抠图」的说明
