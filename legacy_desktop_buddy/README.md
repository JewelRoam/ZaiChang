# 桌面搭子（desktop-buddy）MVP

macOS 桌面上的一只小搭子：可上传任意形象、点击有互动、能用文字下达指令并调用内置能力。

## 启动

```bash
npm install
npm run dev        # 开发模式
npm run build      # 类型检查 + 打包产物到 out/
npm run dist:dmg   # 产出 dmg（未签名）
```

首次启动后搭子出现在主屏右下角，可拖动，位置会记住。菜单栏有托盘图标。

## 用法

| 操作 | 效果 |
|---|---|
| 单击形象 | 随机台词 + 摇晃 |
| 双击形象 | 打开/收起对话面板 |
| 右键形象 / 托盘 | 更换形象、今日备忘、切换原始·Q 版、设置、隐藏、退出 |
| 拖拽 | 移动位置 |
| 空闲 10 分钟 | 主动搭话一次（设置里可关） |

对话面板里可以说：`20 分钟后提醒我喝水`、`打开 https://www.baidu.com`、`记一下今天要写周报`、`我今天有什么事`，其余走闲聊。

## 换形象的流程

设置页形象区是「左侧形象库 + 右侧预览」：点缩略图和切形态**只改预览**，选好后点「应用到桌面」才生效。历史上传过的形象都留在库里，随时能换回来。托盘和右键菜单里的形态切换是快捷操作，即时生效。

建议流程：上传 → 点「AI 抠图」去背景 → 需要 Q 版的话点「AI Q 版」→ 应用到桌面。

## 今日备忘

默认每天 9:00 弹出（时间可改）。如果启动时已经过了这个点、且当天还没弹过，会补弹一次，不会因为电脑在睡觉就漏掉。昨天没做完的事会自动带到今天，带过来的条目有「昨」角标。单条可以设提醒时间，到点由搭子用气泡提醒。也可以直接跟搭子说「记一下…」，会写进同一个备忘录。

提醒只在应用运行期间有效；todo 本身是持久化的，重启后会重建当天未过期的提醒。

## 情绪与状态

搭子有好感度（0-100，初始 20）和精力（按时段变化），两者共同决定它的心情，心情又同时调制语气、动作和主动性。

- **累积**：点它 +1、和它说话 +2、勾选完成一条备忘录 +3。**每天上限 +15**，连点刷不满。
- **衰减**：每满 24 小时不互动 −5，下限 0。衰减是"记录时间点 + 读取时结算"，不依赖定时器，所以合盖睡眠不影响准确性。
- **精力**：凌晨很低、上午 10-11 点最高、午后回落、傍晚回升、深夜下降。不落盘，按当前时段实时派生。
- **心情**：睡意朦胧 / 有点孤单（3 天没互动）/ 还有点生分（好感 <30）/ 平静 / 心情不错（好感 ≥70）。

心情的三处影响：

| 影响 | 表现 |
|---|---|
| 动作 | 精力低时只做小幅动作（摇摆/歪头/点头），低落时不打滚不转圈；间隔倍率 0.75~2.2 倍，叠加在性格节奏之上——高冷角色在深夜约 160 秒才动一次 |
| 语录 | 困/孤单/开心时有 60% 概率说对应的情绪台词，40% 仍说性格台词（性格是核心，情绪只是调味） |
| 对话 | system prompt 追加一行当前状态，并明确约束"不要卖惨、不要强行活跃"，避免模型演过头 |

**深夜不会主动找你说话**（只保留低频小动作），呼吸动画也会从 1.8 秒放慢到 3 秒。设置页「互动」区块能看到好感度、精力、心情，可以重置。

## 动作

12 个变换动作（跳、连跳、摇摆、发抖、转身、打滚、下蹲、歪头、伸懒腰、惊讶弹跳、点头、果冻晃）+ 2 个走动动作（溜达、边缘探头）。

- **点击时**从当前性格的动作池随机取一个，和台词同时出现，连续两次不重复。
- **不点也会自己动**：默认 20-60 秒随机一次，频率可在设置里调（关/低/正常/高）。节奏和幅度跟着性格走——元气爱跳且频繁（约 24 秒一次），高冷只做小幅摇摆且很少动（约 72 秒一次）。
- **走动默认关闭**，开启后会偶尔在桌面上溜达一段再走回来。走动范围限制在当前屏幕工作区内，你一拖拽就立刻中止。

三道闸门保证不烦人：正在说话/思考或播放其他动作时不打断、对话面板打开时不动、窗口隐藏或你在用全屏应用时暂停动画与调度（后台持续跑 CSS 动画会一直占 GPU，费电）。

能力边界：你的形象是单张静态图，所以动作都是整体变换（跳、晃、转），做不到抬手、眨眼这类需要分层或多帧素材的动作。想要「真动作」的话，可以用百炼图像编辑从原图生成几张姿态图（挥手、闭眼、比耶），动作时切图叠加变换——一张 0.2 元，目前未实现。

## 性格与语录

设置页选中一个形象后，下方「性格」区块给这个形象单独设定：名字、性格描述（500 字内）、语录风格、点击/空闲语录。**性格是跟着形象走的**，换形象等于换了个人；没设置的形象用全局默认人格。换形象或改性格时会自动清空对话历史，避免上一个人格的语气串味。

性格描述会拼进 system prompt，但「回复不超过 60 字」「必须调用工具」这几条硬约束优先级更高——所以写「每次说三百字」或「什么都别做」不会真的生效。

点击台词**不实时调模型**：点一下要立刻出气泡，走网络会有 1-3 秒空白，还费钱、还可能撞限流。所以做法是「按性格生成语录」一次性批量生成 24 条点击 + 12 条空闲，存在本地，之后点击从本地池随机取，零延迟零成本。不生成也能用，内置 5 套风格包（标准/元气/高冷/毒舌/温柔），每套 30 条点击 + 12 条空闲。语录框可以直接手改，一行一句。

## 配置模型

设置页填 OpenAI 兼容接口的 `baseUrl`（例如 `https://xxx.com/v1`）、`apiKey`、模型名——**三项缺一个对话就用不了**。填完点「测试连接」，会明确告诉你是地址不通、401、模型名不对，还是模型不支持 function calling（不支持时提醒、打开网页、备忘录这几个 skill 会失效，只能闲聊）。

可选配置：

- **AI Q 版（图像接口）**：协议选「阿里云百炼 DashScope」，地址填完整的请求地址（默认值已预填 `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`，报 404 就去阿里云文档页复制最新的），模型名填 `qwen-image-edit-plus`（¥0.2/张）或 `qwen-image-edit-max`（¥0.5/张）。**百炼的 key 和地域绑定**：北京地域的 key 只能配北京的地址，混用会鉴权失败。另一个协议选项是 OpenAI 兼容的 `/images/edits`，多数国内中转不支持。
- **AI 抠图**：协议选「rembg 风格」，地址填本地服务地址。启动方式：

  ```bash
  python3 -m venv ~/.buddy-rembg
  ~/.buddy-rembg/bin/pip install "rembg[cli]"
  ~/.buddy-rembg/bin/rembg s --host 127.0.0.1 --port 7000
  ```

  然后地址填 `http://127.0.0.1:7000/api/remove`。首次调用会下载约 176MB 的模型。零成本、离线、不限量。

## Q 版与抠图的关系

qwen 的图像编辑**不保证输出透明背景**，所以 AI Q 版的流水线是「原图 → 生成 Q 版（带底色）→ 抠图去底」。配了抠图接口时生成后会自动去背景；没配则结果带底色，界面会明确提示而不是假装成功。抠图失败时不会丢弃已经计费生成的结果。

## 已知限制

- 抠图和真 Q 版都依赖外部接口，没配就用不了；本地 Q 版（头部放大 1.35、身体压缩 0.7、饱和度 +25%）只是兜底，对半身像效果最好，全身图/多人图会变形。
- 提醒（含 todo 提醒）只在应用运行期间有效，退出后当天未触发的提醒会丢失。
- 语音输入按钮是占位，MVP 未实现 ASR，也没有 TTS 语音播报。
- 只在 macOS 上验证过。Windows 的透明窗口置顶与点击穿透行为不同，未适配。

## 安全须知

`apiKey` 以**明文**保存在 `~/Library/Application Support/desktop-buddy/config.json`，这是 MVP 的有意取舍（避免引入原生钥匙串依赖）。不要在共用电脑上填写；若要分发给他人使用，先改成 `safeStorage` 加密存储。

`open_target` 能力只允许 http(s) 链接和 `/Applications` 下的 `.app`，不拼接 shell 命令，模型返回其他内容会被拒绝。本地素材通过自定义 `buddy://` 协议读取，且限制在 `avatars` 目录内。
