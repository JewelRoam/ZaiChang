桌面搭子

一张图 + 一段性格描述，换来一个住在你桌面上、有反应会自己动、还能帮你干活的伙伴。

这是网页版效果演示：下面的动作动画和性格语录都直接取自真实产品，但它只是展示。 真实产品是 macOS 桌面应用 —— 透明置顶窗口、点击穿透桌面、常驻后台、能打开本地应用，这些浏览器做不到。

1 · 换个性格，它就是另一个人

2 · 换成你自己的形象

图片只在你的浏览器里处理，不会上传。真实产品里还能一键 AI 抠掉背景、AI 重绘成 Q 版。

3 · 它有好感度

好感度
20

点它就会积累好感度（真实产品里每天有上限，防止连点刷满；连着几天不理会慢慢下降）。好感度和精力共同决定它的语气、动作幅度和主动性。

4 · 它能干活

真实产品里双击就能跟它说话，它会真的执行：
「20 分钟后提醒我喝水」→ 到点气泡提醒
「打开百度」→ 浏览器直接打开
「记一下今天要写周报」→ 进今日备忘录，每天早上主动弹出
没做完的事第二天自动带过来。

真实产品还有这些

  • 14 个动作，点击触发 + 不点也会自己动，幅度和频率跟着性格走
  • 性格用自然语言写，AI 按描述生成专属语录（写上你的猫叫什么，它真的会提）
  • 深夜会犯困：动作变小变慢、呼吸放缓、不主动找你说话
  • 不填任何 API Key 也能用：换形象、动作、内置语录、备忘录、提醒都在本地
